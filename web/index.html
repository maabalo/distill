# readme

What is Distill?

Distill summarizes text with an AI model that runs on your Mac through Ollama. It's free and private: nothing you paste is sent to the internet.

01 Quick start

  1. Paste text into 01 text, or use open file (or drop a .txt file on it).
  2. Choose the length and format.
  3. Click summarize (or press ⌘ Enter). The summary is written live.
  4. Copy it, or save it as a .txt file.

02 Tips

  • Long text is read in parts, then combined. You'll see "reading part 1 of 3".
  • The first summary takes a few seconds longer while the model loads.
  • Small models can mix up details, especially when one text covers several topics. Check important facts, or choose a bigger model.
  • Get more models in Terminal, for example ollama pull qwen2.5:7b, then reload.

03 If something's wrong

ollama offline
Open the Ollama app (llama icon in the menu bar), then click the status pill to check again.
no models
In Terminal: ollama pull llama3.2:3b, then reload this page.
page won't load
The server isn't running. In Terminal: python3 app.py
